HJY-4GT Vertical Turret Milling Machine Sourcing for Poland

An HJY-4GT vertical turret milling machine order for Poland, covering the selected configuration, workshop checks, accessories, export packing and container loading.

A metalworking customer in Poland asked SARGARA to source one conventional milling machine for repair parts, fixtures and short production runs. The requirement was a practical manual turret mill with power feed, digital position display and easier table-height adjustment for daily workshop use.

The selected model was the **HJY-4GT vertical turret milling machine**. SARGARA coordinated the configuration with the supplier, checked the assembled machine and loose accessories, and followed the export packing through container loading. The photographs on this page belong to that order.

What the Poland customer needed

The machine needed to handle varied workshop jobs rather than one fixed production part: milling flat surfaces, cutting slots and keyways, drilling bolt patterns, boring holes and making replacement components when drawings or quantities changed.

A vertical turret mill fits that work because the table moves in three axes and the head can be positioned for straight or angled operations. The operator can use a vise, clamps, rotary table or a dedicated fixture according to the part being machined.

For overseas sourcing, the general name is not enough. Machines described as “4GT,” “4S,” “turret mill” or “knee mill” can differ in travel, spindle taper, motor, feed systems and included accessories. We therefore kept the working model for this project as **HJY-4GT** and tied the quotation to a written configuration list.

Workpiece tolerance depends on machine condition, setup, cutter, material, feed, depth of cut and the inspection method used at acceptance.

Configuration selected for the Poland order

The base machine was not the full purchasing scope. The order list included several additions intended to make routine manual machining more convenient:

  • Y-axis power feed.
  • Pneumatic tool-change system.
  • Electric Z-axis knee lift.
  • Upgrade from a two-axis digital readout to a three-axis DRO.
  • Export packing.
The three-axis DRO gives the operator a direct position reference for longitudinal, cross and vertical movement. The Y-axis feed supports more consistent table travel than continuous hand feeding, while the electric knee lift reduces manual effort when changing workpiece height or setup.

Pneumatic tool change also needs a clear scope. The buyer should know which spindle taper is supplied, which drawbar system is fitted, the required compressed-air pressure and which holders or collets are included. “Pneumatic tool change” should not be treated as a complete tooling package unless every item is listed.

Workshop check of the assembled machine

The supplier-side photographs recorded the assembled HJY-4GT before export preparation. The machine was checked as a complete unit rather than as a catalog reference.

The workshop views allowed the purchasing team to review the general build and configured components, including:

  • Full table, saddle, knee and column assembly.
  • Milling head, motor and head-positioning mechanism.
  • Digital readout and control panel.
  • Table handwheels and Y-axis power-feed unit.
  • Z-axis lifting arrangement.
  • Electrical cabinet and cable routing.
  • Lubrication components and front table guard.
This was a visual and configuration check. The photographs do not replace geometry inspection, spindle runout measurement, travel accuracy checks or a sample machining test. If those points are critical, the buyer should agree the measuring method, tolerance and report format before the machine is accepted.

Checking loose accessories before packing

Heavy machine tools often arrive with several boxes of parts that are easy to overlook during a general machine inspection. For this order, loose items were grouped in front of the machine so they could be compared with the purchasing scope before packing.

For a milling machine order, a useful accessory checklist should separate standard machine parts from optional tooling. It may include the drawbar, collets or holders, handwheels, lubrication items, work lamp, splash or table guard, leveling pads, toolbox, manuals and electrical diagrams. A vise, rotary table, dividing head or cutter set should only be assumed when it appears in the quotation.

Export packing and container loading

The HJY-4GT is listed at approximately 1250 kg, so the packing base must support the machine at its structural mounting points. The head, ram, table and loose accessories also need to be secured against movement during inland transport, lifting and sea shipment.

For this Poland order, the machine was protected and fixed inside a timber shipping frame before being positioned in the export container.

The loading photograph records the actual packed machine and its position in the container. Before shipment, the buyer should also confirm lifting points, center of gravity, forklift access, moisture protection and the unloading equipment available at the destination workshop.

What a buyer should confirm before ordering a turret mill

A useful RFQ starts with the parts and operations, not only the machine model. Overseas buyers should provide:

  • Workpiece material, maximum dimensions and weight.
  • Required milling, drilling, boring and reaming operations.
  • Critical tolerances and surface-finish requirements.
  • Preferred spindle taper and existing tooling standard.
  • Cutter, collet, holder, vise and fixture requirements.
  • Manual or powered feed requirements for each axis.
  • DRO axis count and preferred display brand, if specified.
  • Site voltage, frequency and phase.
  • Pneumatic supply available in the workshop.
  • Guarding, manuals and conformity-document requirements.
  • Installation, commissioning and operator-training expectations.
  • Destination, unloading method and available floor space.
For close-tolerance work, add a sample part or acceptance test. A general statement such as “precision milling machine” does not define flatness, perpendicularity, hole position, spindle runout or repeatability.

FAQ

What is a vertical turret milling machine used for?

A vertical turret milling machine is used for general milling, drilling, boring, slotting and repair work. Its movable knee and table, together with a positionable head, make it suitable for toolrooms, maintenance workshops, prototypes and short production runs.

What table size does the HJY-4GT have?

The supplied specification lists a 1270 x 254 mm table with 700 mm X-axis travel, 380 mm Y-axis travel and 400 mm Z-axis knee travel. Maximum table load is listed as 300 kg.

Does the HJY-4GT use an R8 or NT30 spindle?

The parameter sheet shows R8 with an NT30 reference or option. The quotation must state the selected spindle taper because the drawbar, holders, collets and pneumatic tool-change components depend on it.

Which upgrades were included for the Poland order?

The supplied order list included Y-axis power feed, pneumatic tool change, electric Z-axis lift and a three-axis digital readout upgrade.

Was the milling machine tested for accuracy?

The available records support an assembled-machine and accessory check plus packing and loading follow-up. They do not establish geometry or machining accuracy. Those tests require an agreed procedure, calibrated instruments and written acceptance limits.

Can SARGARA arrange a pre-shipment milling machine inspection?

SARGARA can coordinate a supplier-side or third-party inspection scope covering configuration, accessories, electrical data, basic operation, measurements, sample machining and packing. The buyer should define the required checks and acceptance criteria before inspection.
