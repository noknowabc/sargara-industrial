Product Overview

Rexroth Material Number R930050353 corresponds to type code 08356265723500B / A-VBSO-SE-CCAP33PSE34SAE, a compact single counterbalance valve for compatible mobile and industrial hydraulic circuits.

A counterbalance valve is generally used in a load-holding circuit to help prevent an actuator from running ahead of the supplied flow and to support controlled movement under load. That is the product family's general function; the exact behavior of this code depends on its internal configuration, setting and circuit connection.

Replacement selection should keep the material number and complete type code together. Pressure setting, flow, pilot ratio, ports and circuit function must match the original valve and hydraulic schematic.
