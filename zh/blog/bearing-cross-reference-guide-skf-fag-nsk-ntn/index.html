轴承交叉参考指南：如何匹配SKF，FAG，NSK和NTN

了解如何使用尺寸，轴承类型，清除，密封，子和后音代码来对SKF，FAG，NSK，NTN等品牌的工业轴承进行交叉参考。

如何将工业轴承进行交叉引用？

首先要从轴承名称和制造商的完整信息开始，然后比较轴承类型，边界尺寸，内部设计，清除，密封或屏蔽，子，精度和操作要求。两个品牌的相同基本数字可能表明相似的大小，但它不会自动证明每个后尾和性能细节都相当。

这就是轴承交叉参考工作的核心规则：尺寸是起点，而不是最终批准。

本指南是针对试图替换SKF，FAG，NSK，NTN，KOYO，NACHI或其他工业轴承的维护团队，分销商和设备所有者。 在要求供应商更换或批准替代品之前，该指南说明该收集哪些信息。

区分基本名称和完整代码

轴承名称通常有基本号码加上可选的先和后。基本号码通常标识着轴承家族和尺寸系列。额外的字符可以描述内部清除，密封，屏蔽，子设计，接触角，耐受性类，滑特性，匹配布置或制造商特定的变化。

考虑一个常见的深球轴承。 △6004`的基本代码与△6004-2Z`的购买描述不同。后者在SKF命名中指定了两侧的金属盾牌。一个开放的轴承或密版本可能具有相同的20 x 42 x 12mm边界尺寸，但它不是相同的配置。

为什么仅仅尺寸不够

测量孔，外径和宽度是有用的，当代码是不可读的。这些三个维度可以缩小搜索，但许多轴承变化共享相同的包裹。

金属罩轴承，密轴承和开放轴承都可能适合相同的套装。正常清除轴承和C3清除轴承也可能具有相同的尺寸。安装后，它们的行为可能不同，特别是适合，速度，热量或污染物质时。

如果有旧轴承，请收集：

  • 两张戒指面孔的清晰照片和可见的标记。
  • 如果原装仍然存在，则收藏和标签照片。
  • 孔，外径和宽度。
  • 轴承类型和环是否分开
  • 封印或盾牌的外观
  • 机器的制造，模型和轴承位置。
  • 轴的速度，载荷方向，温度和污染记录，如已知。
  • 任何旧的购买记录，零件手册或组装图。
磨损轴承可能会出现热变色，车道损坏或缺失密封。 声明采样使用；不要假设其目前的状况代表原标。

轴承后音必须按函数翻译

交叉参考表是有用的，但在选择其他品牌之前，应将后音转换为其工程意义。例如，后音可能表明比正常更大的清除，加工的黄铜子，金属屏蔽，滑槽或特定的接触角。另一家制造商可能用不同的字母表达相同的特征，或者可能不提供直接目录等级。

使用每个制造商的当前官方目录或产品数据。不要仅仅从旧第三方表的截图中构建RFQ。标签名称和可用的变体可能会发生变化，有些代码仅适用于产品家族。

七步轴承交叉参考过程

1。记录原始身份证明

清洁或处理之前，请复制完整的代码和标签。

2。 确认轴承家族

确定是否是半径球轴承，角接触轴承，圆柱形或圆形滚动轴承，推力轴承，针轴承或其他类型。不要根据钻孔大小推断家族。

3。 确认尺寸和接口

检查孔，外径，宽度，肩膀几何以及任何快戒槽，，孔或适配器布置。

4。 解码后音

列出每一个已知特征：清除，子，密封，精度，滑和匹配的布置。

5。 进行操作要求的比较

如果原始代码过时或无法使用，请提供速度，射线和轴轴向负载方向，温度，适应，滑和环境。替代可能需要应用程序审查而不是简单的代码交换。

6。 要求明确报价

要求供应商说明是否提供了准确的品牌和代码，目前的继任者，尺寸匹配或拟议的功能替代品。

7。 在运输前批准

对于一项订单，请检查模型标记，数量，包装和可见状态。 对于真实性而言，在支付前确定供应道和品牌验证路线。 单独的照片不能证明品牌轴承是真实的。

究竟是什么替代品，是继任者还是重新设计？

对于一个老旧的代码，可能会有制造商列出的继任者。一个具有相同尺寸的标准轴承可能是审查的候选人。在困难的情况下，机器组装可能需要重新设计。

这些航线不应被视为等等：

  • **准确的替换：**同一个制造商和完整的名称。
  • **制造商继任者：**正式取代了更新的名称，须确认。
  • **跨品牌相当品：**来自另一家制造商的拟议匹配产品。
  • **维度候选：**适合相同的包裹，但需要技术比较。
  • **应用重新设计：**轴承配套或周围部件的变化。
对于关键设备，高速，配轴承或不寻常的负载，最终选择应由买方的工程师或合格的轴承应用工程师批准。

FAQ

SKF，FAG，NSK和NTN轴承是否可以使用相同的基本号码？

许多标准化轴承家族的基本数量和边界尺寸都相似。 然而，后音，内部设计和目录细节可能不同，因此必须比较完整的名称。

只有，外径和宽度才能更换轴承？

这些尺寸可以识别候选人，但它们不能证实清除，密封，子，精度，接触角或内部布局。 通常需要额外的信息。

在轴承上，C3意味着什么？

在相关轴承命名中，C3通常表示半径内部清除比正常高。 在订购之前，确认目前制造商的产品文件中对产品家族的确切含义。

标签之间的后音代码是否相同？

没有。有些后音类似，而有些则是制造商或产品家族特定的。

萨拉加可以批准我的机器的轴承等级吗？

SARGARA可以组织数据和供应商通信。 最终技术批准应由采购商的工程师，机器制造商或经过实际应用条件的合格轴承专家获得。
